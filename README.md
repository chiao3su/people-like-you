# 和你一樣的人 People like you, taken away

輸入你現在的年齡、性別和職業，看看 1947–1992 年間，有多少跟你一樣的人因政治案件被捕、受審。

## 檔案

- `index.html`：整個頁面（HTML、CSS、JavaScript 都在這一個檔案裡）
- `data.json`：從臺灣轉型正義資料庫整理出的 14,946 筆資料（約 2 MB）
- `.nojekyll`：讓 GitHub Pages 直接提供檔案，不經 Jekyll 處理

## 放上 GitHub Pages

1. 在 GitHub 建立新的 repository，把這三個檔案放在根目錄並 push。
2. 到 repository 的 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
3. 約一分鐘後，網址會是 `https://<你的帳號>.github.io/<repository 名稱>/`。

## 在本機預覽

頁面用 `fetch` 讀取 `data.json`，直接雙擊打開 `index.html` 會被瀏覽器擋下。請在這個資料夾開一個本機伺服器：

```bash
python3 -m http.server 8000
```

再到瀏覽器打開 http://localhost:8000 。

## data.json 欄位

`occ` 是職業分類名稱。`rows` 每一筆是一個陣列：

| 位置 | 內容 |
|---|---|
| 0 | 性別：0 男、1 女、-1 未載 |
| 1 | 受審時年齡，-1 為未載 |
| 2 | 職業分類（`occ` 的索引），-1 為未載 |
| 3 | 最終判決或處分的西元年，0 為未載 |
| 4 | 刑度代碼：D 死刑、L 無期徒刑、T 有期徒刑、E 感化教育、N 無罪／免訴／免刑、P 不起訴、空字串為未載 |
| 5 | 刑度文字 |
| 6 | 姓名 |
| 7 | 原始職業文字 |
| 8 | 判決所載理由（第一份有記載的文書，超過 150 字截斷） |

## 資料處理說明

- 刑度與年代取自資料庫的最終判決欄位（`f_` 開頭）。
- 職業原本是 4,985 種自由文字，以關鍵字粗分為 15 類，可能有誤差。
- 判決理由為當年文書原文，用語是官方當時的用語，不是事實認定。

## 資料來源

促進轉型正義委員會「臺灣轉型正義資料庫」，14,946 筆，2022 年 4 月 20 日版。
